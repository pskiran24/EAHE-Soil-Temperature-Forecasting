# EAHE Forecasting Notebooks

This directory is intended for reviewed, sanitized notebooks documenting the forecasting experiments.

## Planned Notebooks

- `eahe_forecasting.ipynb` — baseline forecasting models and stacking experiments.
- `eahe_pinn.ipynb` — physics-informed neural network experiments.
- `dataset_split.ipynb` — dataset preparation and splitting, if suitable for publication.

## Data Access

The original EAHE dataset is restricted and is not included in this repository. Running the experiments requires authorized access to the data.

Notebooks will be added only after checking source code, outputs, metadata, file paths, and embedded content for confidential information.
